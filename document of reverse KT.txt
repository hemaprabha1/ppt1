1. Introduction
What is BFL CMS?

The CMS (Card Management System) is a wallet and prepaid card management platform used by Bajaj Finserv.

It provides APIs for:

Customer onboarding
Wallet management
KYC management
Credit/Debit transactions
Fund transfers
Balance inquiry
Statements
Fastag operations
Limit management
Lien management

2. Common Framework Concepts
Request Header

Every API contains:

Institution ID
Channel Identifier
Request Type
User ID
Request Date/Time
Request Reference Number
Example

Customer Raj registers a wallet from Mobile App.

{
 "institutionId":1001,
 "channelIdentifier":"MB",
 "requestType":"SU"
}

Authentication Concept

Before invoking any API:

Step 1

Call Login API

Step 2

Receive AUTH TOKEN

Step 3

Use token in all APIs

Scenario

Customer opens Bajaj App.

App calls Login API
Receives Auth Token
Uses token for Signup, Credit, Debit, Inquiry APIs
3. Login API (LA)

4. Dedupe Check API (DD)
Purpose

Prevent duplicate wallet creation.

Checks:

Mobile Number
PAN
Passport
Driving License
Name Matching
Scenario

Customer:

Mobile: 9876543210
PAN: ABCDE1234F

Before Signup:

CMS verifies if customer already exists.

Result
Success

No wallet exists.

Wallet Creation Allowed

Failure

Wallet already exists.

Existing Wallet Details Returned
